## 1. Proxmox VE 9 — PwnEscape corrigée

**CVE-2026-99999 (« PwnEscape »)** : le bulletin officiel **PSA-2026-00068-1**, publié le 16 octobre, confirme le correctif dans `proxmox-kernel-7.0.14-24-pve(-signed)`.

- **Impact :** une VM KVM contrôlée par un attaquant peut provoquer une fuite mémoire de l'hôte et potentiellement une exécution de code sur celui-ci.
- **Vecteur et prérequis :** contrôle préalable d'une VM ou d'une charge invitée ; pas de RCE directement exploitable depuis Internet sans accès préalable ; aucune interaction utilisateur.
- **Action P0 :** installer le kernel corrigé, redémarrer les hyperviseurs et vérifier `uname -r`. Conserver un noyau de secours bootable.

Autres avis Proxmox à considérer :
- **PSA-2026-00067-1** : écriture arbitraire de fichiers lors d'extraction VMA, corrigée dans `pve-qemu-kvm >= 11.1.1-2`.
- **PSA-2026-00066-1** : traversée de chemins dans l'importateur ESXi, corrigée dans `libpve-storage-perl >= 9.1.12`.

Dernières versions no-subscription identifiées : kernel `7.0.14-24-pve` et `pve-manager 9.2.21`.

Sources :
- https://forum.proxmox.com/threads/proxmox-virtual-environment-security-advisories.149331/
- https://github.com/proxmox/pve-kernel/blob/master/debian/changelog

# MCO Daily — 1er octobre 2026

## Résumé exécutif

🔴 **GitLab reste prioritaire** : le Critical Patch Release du 23 septembre reste le dernier identifié. Les cibles sont `19.4.1`, `19.3.3` et `19.2.7`, avec 11 vulnérabilités corrigées dont deux RCE CI/CD critiques CVSS 9.9.

🔴 **Rocky/RHEL 9 : nouveau kernel `5.14.0-687.53.1.el9_8`**. Il remplace `687.52.1` comme cible MCO et correspond à **RHSA-2026:72623**, qui corrige 9 CVE kernel.

🟡 **Proxmox VE** : pas de nouvelle version pertinente après `pve-manager 9.2.21`. Le kernel production suivi reste `7.0.14-19-pve`; ne pas promouvoir un build provenant uniquement de pve-test.

# Rocky Linux / RHEL 9

## Nouveau kernel — action MCO

```text
5.14.0-687.53.1.el9_8
RHSA-2026:72623
Publication Rocky : 29 septembre 2026
```

Le dépôt Rocky Linux 9 BaseOS x86_64 publie désormais `687.53.1`. L'advisory associé corrige :

- CVE-2026-45942
- CVE-2026-46325
- CVE-2026-52972
- CVE-2026-53341
- CVE-2026-63875
- CVE-2026-64102
- CVE-2026-64556
- CVE-2026-74753
- CVE-2026-80522

Ces vulnérabilités couvrent plusieurs classes de corruption mémoire et erreurs de concurrence du kernel. Le rapport reste volontairement défensif : aucune procédure d'exploitation n'est fournie.

**Action MCO :**
- déployer `5.14.0-687.53.1.el9_8` sur les Rocky 9 ;
- planifier le reboot ;
- vérifier après redémarrage avec `uname -r` que `687.53.1` est actif ;
- considérer les kernels antérieurs à `687.53.1` comme non corrigés pour les CVE de RHSA-2026:72623.

# GitLab Self-Managed CE/EE

## Critical Patch Release toujours en vigueur

```text
19.4.x -> 19.4.1
19.3.x -> 19.3.3
19.2.x -> 19.2.7
```

GitLab recommande l'installation immédiate de ces versions sur les instances Self-Managed affectées.

### Vulnérabilités prioritaires

| Criticité | CVE | Impact | Conditions principales | Corrigé |
|---|---|---|---|---|
| 🔴 Critical 9.9 | CVE-2026-89078 | **RCE serveur / CI/CD** | réseau, utilisateur authentifié à faibles privilèges, aucune interaction | 19.2.7 / 19.3.3 / 19.4.1 |
| 🔴 Critical 9.9 | CVE-2026-93577 | **RCE serveur / CI/CD** | réseau, utilisateur authentifié à faibles privilèges, aucune interaction | mêmes versions |
| 🟠 High 8.7 | CVE-2026-84739 | XSS dans le diff viewer de Merge Request | utilisateur authentifié + interaction victime | mêmes versions |
| 🟠 High 7.7 | CVE-2026-92470 | **exposition de variables CI/CD** via Duo AI | GitLab EE, authentification requise | mêmes versions |
| 🟡 Medium 5.4 | CVE-2026-92874 | permissions excessives avec token MCP | token MCP authentifié | mêmes versions |
| 🟢 Low 3.7 | CVE-2026-4523 | **lecture non authentifiée de traces CI/CD** dans certaines conditions | réseau, aucune authentification, complexité élevée | mêmes versions |

### Signaux MCO

- **RCE :** CVE-2026-89078, CVE-2026-93577.
- **CI/CD :** RCE via configuration CI/CD et exposition possible de variables/traces.
- **Secrets/tokens :** CVE-2026-92470 et CVE-2026-92874.
- **Sans authentification :** CVE-2026-4523.
- **Auth bypass critique :** aucun nouveau cas critique identifié dans cette release.

**Action MCO :** une instance encore en `19.3.2` doit passer au minimum en `19.3.3`. Cette patch release comprend des migrations de base de données ; prévoir l'indisponibilité correspondante sur une instance single-node.

# Proxmox VE

## État du jour

```text
Proxmox VE       9.2
pve-manager      9.2.21
kernel prod      7.0.14-19-pve
```

Aucun nouveau delta important identifié depuis `pve-manager 9.2.21`.

Cette version reste particulièrement pertinente pour les environnements Ceph/Cephx :
- nettoyage des clés lockbox et dm-crypt lors de la destruction d'OSD chiffrés ;
- corrections de migration Cephx sur les nœuds utilisant des FQDN ;
- garde-fous supplémentaires pendant la rotation des clés ;
- dépendance sur `libpve-storage-perl >= 9.1.9` pour les keyrings contenant une clé aes256k.

**Action MCO :**
- intégrer `pve-manager 9.2.21` dans la fenêtre normale, avec priorité aux clusters Ceph ;
- conserver `7.0.14-19-pve` comme référence kernel production suivie ;
- ne pas forcer un kernel uniquement disponible dans pve-test.
